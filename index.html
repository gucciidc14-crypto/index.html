RP NAME CHECK

Type your character name to see if it passes.

Example format: James_Walker

    Rules used
    • Format: Firstname_Lastname (one underscore)
    • English letters only, no numbers or symbols
    • Each name starts with a capital, rest lowercase
    • Each name is 3 to 15 letters and has a vowel
    • No letter three times in a row
    • First and last name can’t be identical
    • No offensive words, staff titles, or famous/fictional names

    These are common RP server rules. Your server’s own rules may differ.
